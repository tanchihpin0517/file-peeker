一百種組合不是一百份程式碼。排版只決定哪個矩形畫在哪、那個矩形扮演什麼角色； 色票只把角色換成顏色。兩邊唯一的接觸面是下面這組角色名 —— 這正是 src/gui/theme.rs 已經在做的事 （named roles rather than named colours）， 差別只在多了三個桌面才有的角色，以及排版現在也一起可選。

j k 換排版，h l 換配色，d 換深淺，[ ] 換視窗尺寸。 尺寸單位是 egui 的邏輯點，列高 26、縮排 15、圓角 7、髮絲線 1px，全部取自 src/gui/theme.rs 與 src/gui/dock.rs 現在的值。 內容是真的：連線是 Local 與兩台 SSH（其中一台斷線），檔案是這個 repo， 欄位是 Name 與 Status，狀態只有 loading / unreadable / file / link / other， 進行中的傳輸是 report.pdf。
